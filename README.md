# 🏋️ CoreFit Gym E-Commerce Website

A modern, responsive gym website that combines fitness services with an e-commerce experience. Users can explore gym offerings, browse fitness products, and manage items through a fully functional shopping cart system.

---

## 🚀 Live Demo

🌐 **Live Site:** https://corefit-gym.vercel.app/  
📂 **GitHub Repository:** https://github.com/estheroluwabuyi/corefit-gym  

---

## ✨ Features

- 🏋️ Gym services showcase section  
- 🛒 Fitness product listing (gear, supplements, accessories)  
- ➕ Add to cart functionality  
- 🗑️ Remove items from cart  
- 💾 Cart persistence using local storage  
- 🎯 Smooth and interactive UI experience  
- 📱 Fully responsive across all devices  
- 🎬 Animations for better user experience  

---

## 🛠️ Tech Stack

- React.js  
- JavaScript (ES6+)  
- Tailwind CSS  
- Framer Motion  
- Local Storage API  
- Vercel (Deployment)

---

## 🎯 Project Purpose

This project was built to improve my frontend development skills, focusing on:

- Building real-world e-commerce UI flows  
- State management in React  
- Component-based architecture  
- Creating interactive user interfaces  
- Working with local storage for persistence
